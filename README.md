# Casino Project

This project is a casino-style web application built to demonstrate backend development, authentication, routing, and user interaction through a web interface.

## Features

- User login and signup pages
- Casino-themed interface
- Backend application structure
- HTML/CSS styling
- Local development support

## Technologies Used

- Java / Spring Boot
- HTML
- CSS
- Thymeleaf
- Maven

## How to Run

```bash
./mvnw spring-boot:run
```

Then open:

http://localhost:8080

Note:

This project is for educational purposes and does not use real money or gambling functionality.
